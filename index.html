Elemental Affinities

Persona/SMT-styled Element Affinity (Status) table in Owlbear Rodeo

Connecting to Owlbear Rodeo...

How To Enable:

  1. Import into Owlbear Rodeo using it's manifest.json in the github repo
  2. Open Context Menu on a TOKEN and open the Elemental Affinity table
  3. Enable "Use This Plugin"
  4. Set parameters for levels and affinities
