Element-Weakness Overlay for Owlbear Rodeo

A work in progress plugin for Owlbear Rodeo SDK.

Features:

  1. Element Overlay — Hovering on a Token gives a grid-based display of its known element vulnerabilities, resistances, and immunities.
  2. GM Screen Filtering — Set the elemental types on the GM's screen and enable their view for players separately.
  3. Icons — Included icons for elements for visual simplicity.
